# Approved heavy bag

Approved by the user on 14 October 2026.

heavy_bag.png is the 128 x 192 side-view pixel-art sprite. Import settings: single Sprite, Point filtering, uncompressed, no mipmaps, full rectangle, 64 pixels per unit. Custom pivot is at the top visible chain pixel (64,178) for future swing animation. Pixel density is a technical starting point for the future gym scene.

Source~/heavy_bag.blend contains the editable model, lighting, and orthographic camera. The trailing ~ keeps the source folder out of Unity's asset import pipeline; the game uses the 2D PNG. The Blender source remains beside the sprite.

This is a static visual asset. Gameplay, collision, animation, equipment placement, and scene integration remain to be built.
