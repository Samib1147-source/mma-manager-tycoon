# Approved pad storage shelf

User-approved worn steel and timber storage shelf. One 160 x 128 sprite, Point filtering, no compression or mipmaps, Full Rect, 64 pixels per unit. Bottom-contact pivot: (0.5, 0.09375).

The editable Blender source is in Source~/storage_shelf.blend, beside the sprite and excluded from Unity's import pipeline. Warm overhead light and cool fill are baked into the sprite. The training pads are a separate asset. Placement in the complete gym background is a later step.
